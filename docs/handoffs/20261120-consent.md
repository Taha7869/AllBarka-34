## What Was Done

### 1. Consent State, Policy Version & Code-Derived Inventory (`src/lib/consent.ts`)
- Defined `CONSENT_POLICY_VERSION = '2026-11-20'` and `CONSENT_STORAGE_KEY = 'allbarka_consent_v1'`.
- Implemented `needsConsentPrompt`, `hasEffectiveConsent`, `isGpcEnabled`, `generateAnonymousConsentId`, `parseStoredConsent`, `readStoredConsent`, `writeStoredConsent`, and strict `validateConsentLogPayload`.
- Policy version bumps automatically re-prompt visitors and block optional categories until re-consented.
- Authored `STORAGE_INVENTORY`: complete trilingual (EN/UR/AR) inventory of all real cookies, `localStorage`, `sessionStorage`, and gated script categories found in the codebase (`__session`, `allbarka_consent_v1`, `allbarka_cart_v1`, `allbarka_selected_addons_v1`, `allbarka_delivery_city`, `allbarka_language`, `allbarka_theme`, `allbarka_currency_preference`, `allbarka_saved_products`, `allbarka_saved_boxes_v1`, `allbarka_addresses_v1`, `allbarka_compare_v1 & allbarka_recent_v1`, `allbarka_pwa_dismissed`, checkout/order/reload `sessionStorage` keys, `allbarka_seen:*`, and future gated scripts).

### 2. Rate-Limited Anonymous Server Audit Route (`src/lib/consentRouter.ts`, `server.ts`)
- Added `POST /api/consent` gated by `consentLimiter` (`20 req/min`).
- Strictly validates `{ anonymousId, categories: { necessary: true, analytics, marketing }, policyVersion, timestamp, gpc }` and strips all extra/PII fields.
- Never reads or persists IP, user-agent, cookies, UID, email, or phone. Writes only anonymous audit entries to Firestore `consentLogs` (default-denied to browser SDKs in `firestore.rules`), returning `201` (Firestore) or `202` (offline/unconfigured) with `Cache-Control: no-store`.
- Documented `POST /api/consent` as row #23 in `docs/security/ROUTE_AUDIT_20261119.md`.

### 3. `useConsent()` Hook & `ConsentGate` (`src/contexts/ConsentContext.tsx`, `src/components/ConsentGate.tsx`)
- Mounted `<ConsentProvider>` in `src/main.tsx` with cross-tab `storage` synchronization and Global Privacy Control (`navigator.globalPrivacyControl === true`) default-off enforcement for Analytics and Marketing.
- Created `<ConsentGate category="analytics" | "marketing" | "necessary" onGranted={...} />` + `loadConsentScriptOnce` helper so future Google Analytics / Meta Pixel scripts strictly wait for explicit consent.
- Updated `src/lib/demandTracking.ts` to also respect explicit `analytics: false` stored consent alongside DNT and GPC.

### 4. Luxury Consent Banner & Preference Panel (`src/components/CookieNotice.tsx`, `src/layouts/RootLayout.tsx`)
- Banner displays 3 equal-size (`min-h-[44px]`, equal width/height) actions in EN/UR/AR: **Accept all**, **Reject all**, and **Choose preferences**, plus a GPC indicator badge when GPC is active and a link to `/policies/cookies`.
- Preference modal (`role="dialog" aria-modal="true"`, Escape to close, scroll lock, RTL & dark mode parity, `useReducedMotion()`) displays **Essential** (always on), **Analytics** (toggle), and **Marketing** (toggle) with full EN/UR/AR explanations and policy version.
- Positioned on mobile at `bottom-[calc(5.25rem+env(safe-area-inset-bottom))]` (above the floating AI chat button) and coordinated with `PwaInstallBanner` (`consentUiActive`) and `RootLayout` modal/cart/checkout guards so it never overlaps other mobile controls.

### 5. Footer Reopen Link & `/policies/cookies` (`src/components/Footer.tsx`, `src/components/CookiePolicySection.tsx`, `src/pages/PoliciesPage.tsx`)
- Added `/policies/cookies` link in Footer Support column + **Cookie settings** (`footer.cookieSettings` in EN/UR/AR) trigger button in the Footer bottom bar to reopen the preference modal at any time.
- Extended `PolicyTab` and `normalizePolicyTab` to support `/policies/cookies` (page and modal), rendering `CookiePolicySection` directly from `STORAGE_INVENTORY` with responsive desktop table / mobile cards, GPC note, policy version, and a **"Manage cookie settings"** button.
