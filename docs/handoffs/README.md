# Handoff notes

One file per finished task, newest by date in the name: `<yyyymmdd>-<short-task>.md`. Written by whichever agent did the work (Antigravity on `ag/*` branches, Claude on the deploy branch), read by the other at `/start`.

Each note: what changed (files), how it was checked (command and result line), what is left, owner decisions needed. No secrets.
