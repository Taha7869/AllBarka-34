# AllBarka Stage 7: n8n AI Consultant Workflow Specification

This document details the external n8n workflow contract for the **AllBarka AI Shopping & Celebration Buddy** (Stage 7). In accordance with Stage 7 safety requirements, this specification is committed to the repository for review without mutating the live production n8n instance.

---

## 1. Integration Architecture

```
[Customer Browser / AIConcierge.tsx]
       │
       ▼ (HTTPS POST with session / optional Google token)
[Express Server (/api/concierge/chat)]
       │
       ├─ Authenticates user / enforces guest rate limits
       ├─ Queries authoritative Firestore catalog (with fresh dynamic sync)
       ├─ Constructs grounded system prompt with packaging MOQ & store policies
       │
       ▼ (HTTPS POST + X-AllBarka-Webhook-Secret)
[n8n Webhook Endpoint (N8N_AI_WEBHOOK_URL)]
       │
       ├─ Validates secret header
       ├─ Executes Groq LLM node (llama-3.3-70b-versatile)
       └─ Returns structured JSON response
       │
       ▼ (HTTPS 200 JSON Response)
[Express Server (/api/concierge/chat)]
       │
       ├─ Validates recommended product IDs against authoritative catalog
       ├─ Validates inquiry prefill against packaging MOQ & resolveInquiryProductVariant
       ├─ Computes deterministic packaging subtotal in application code
       └─ Returns clean response to browser
```

---

## 2. Inbound Contract (`Express -> n8n`)

- **Method**: `POST`
- **Headers**:
  - `Content-Type`: `application/json`
  - `X-AllBarka-Webhook-Secret`: `<32+ char secret configured in N8N_AI_WEBHOOK_SECRET>`
- **Payload Schema**:
  ```json
  {
    "source": "website",
    "message": "I need 50 wedding favor boxes for my Nikkah next month.",
    "history": [
      { "role": "user", "text": "Assalam-o-Alaikum" },
      { "role": "assistant", "text": "Walaikum Assalam! Welcome to AllBarka..." }
    ],
    "system": "<Authoritative system instruction generated by buildBuddySystemInstruction>"
  }
  ```

## 3. Outbound Contract (`n8n -> Express`)

The workflow must return an HTTP 200 with a JSON object.

### Structured Response Schema (Stage 7)

```json
{
  "reply": "For your Nikkah celebration, I recommend our Luxury Tin Bid Box...",
  "action": "answer",
  "recommendedProductIds": [
    "bid-box-luxury-tin",
    "bid-box-umrah-tabarruk"
  ],
  "inquiryPrefill": {
    "productId": "bid-box-luxury-tin",
    "packagingVariant": "Empty Box (1 pc)",
    "boxMode": "empty",
    "quantity": 50,
    "eventType": "Nikkah",
    "targetEventDate": "2026-11-20",
    "budgetType": "total",
    "targetPricePkr": 18000,
    "preferredFillings": ["dry_fruits", "dates"],
    "customFillingsNotes": "Almonds and Ajwa dates",
    "monogramText": "Zain & Fatima",
    "cardMessage": "Best Wishes",
    "customPrintText": "Gold foil stamping",
    "city": "Lahore"
  }
}
```

### Supported Envelopes (Backward-Compatible)

The repository's `extractN8nReply` function in `src/services/n8nAIConsultant.ts` supports:
1. **Direct structured object**: `{ reply: "...", action: "answer", recommendedProductIds: [...] }`
2. **Markdown-wrapped JSON string**: `{ reply: "```json\n{\"reply\":\"...\",\"action\":\"answer\"}\n```" }`
3. **Legacy text envelopes**: `{ text: "..." }`, `{ output: "..." }`, `[{ reply: "..." }]`
4. **Human escalation**: `{ action: "human", reply: "Please connect with our team on WhatsApp." }`

## 4. n8n Node Configuration Details

### Node 1: Webhook Trigger
- **HTTP Method**: `POST`
- **Path**: `/webhook/allbarka-ai-consultant`
- **Response Mode**: `When Last Node Finishes`

### Node 2: Header Validation (IF node)
- **Condition**: `$headers['x-allbarka-webhook-secret'] === $env.N8N_AI_WEBHOOK_SECRET`
- **On False**: Return HTTP 403 `FORBIDDEN`.

### Node 3: Groq LLM Node
- **Model**: `llama-3.3-70b-versatile` (or `mixtral-8x7b-32768`)
- **Temperature**: `0.3` (restrained, accurate, low hallucination)
- **Max Tokens**: `1024`
- **Response Format**: `json_object`
- **Prompt Mapping**:
  - `System`: `{{ $json.system }}`
  - `User`: `{{ $json.message }}`
  - `Messages History`: `{{ $json.history }}`

### Node 4: Format Response (Code node)
```javascript
let raw = $input.first().json;
let content = raw.message?.content || raw.reply || raw.text;

// If model returned a JSON string, parse it
if (typeof content === 'string' && content.trim().startsWith('{')) {
  try {
    const parsed = JSON.parse(content);
    return [{ json: parsed }];
  } catch (e) {
    // fallback to plain text
  }
}

return [{
  json: {
    reply: typeof content === 'string' ? content : 'How may I assist you with AllBarka dry fruits or celebration packaging today?',
    action: 'answer'
  }
}];
```
