## How to use

1. Settings: aspect **4:5** (if the tool has no 4:5, use 3:4 and say so when you send the file), highest quality model, two results per prompt.
2. Start with **IMG-0001 and IMG-0004 only**. Send both for a look check before spending on the other eight.
3. Paste one prompt exactly as written. Do not add text, names or logos; label areas must stay blank.
4. Pick the better result and check it: buildable box, right format, no letters or symbols anywhere, blank label, whole object visible with space around it, travertine surface, no yellow cast.
5. Download the largest PNG and name it with the ID, for example `IMG-0001.png`. Attach the files in chat or hand them to the agent that is committing; they are converted to WebP (long edge 1600 px, under 250 KB) and saved at the target path below.
6. One design, one tool: keep every image of a design in the tool that made its first image, so the look stays consistent.

After the image is committed, the design appears on the website only when its `image` path is set and the owner turns on `publishApproved` in `src/config/celebrations.ts`.
